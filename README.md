## About Me

- **Automation:** Playwright (TypeScript) and Selenium (Java + TestNG), Page Object Model with custom fixtures
- **API testing:** Playwright `request` fixture and REST Assured, with JSON-schema contract validation (AJV)
- **Database testing:** MySQL verification inside the same suite as UI and API layers
- **CI/CD:** Jenkins declarative pipelines and GitHub Actions, with archived reports, traces and build emails
- **Reporting:** Playwright HTML, JUnit XML, Allure, Extent Reports and a custom dashboard reporter
- **Also:** manual testing, test design, Jira, Git

## Projects

### 1. PLAYWRIGHT_OPENCART_AI_V1 — Hybrid Playwright Framework

🔗 [Repository](https://github.com/sagar-bankar/PLAYWRIGHT_OPENCART_AI_V1)
&nbsp;·&nbsp; 🔗 [Project page](https://sagar-bankar.github.io/PLAYWRIGHT_OPENCART_AI_PORTFOLIO/)

Hybrid Playwright + TypeScript framework covering web UI, REST API and MySQL in one layered
codebase. 48 tests in CI across 8 Page Objects and 26 API routes, with typed fixtures,
AJV schema contracts, a custom HTML dashboard, Allure reporting, Docker support and a Jenkins
pipeline that mails the report links after every run. AI-assisted development is documented
through `playwright_mcp_context.md`.
